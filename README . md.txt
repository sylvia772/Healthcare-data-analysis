
 HOSPITAL DATA ANALYSIS REPORTS

Introduction; This is a data set showing patient id, Admission Date, age, gender, diagnosis etc the objective of the data was to clean it in terms of removing duplicates, checking for missing values and derive insight from the data

Data Cleaning:

While working with this data set, i realize that certain parts of the data had missing values and they were replaced as unknown, because filling in a new value will distort the data set


   Objectives:

	•	Identify and handle missing and duplicate values
	•	Clean and format data for consistency
	•	Generate insights such as patient age distribution, gender breakdown, diagnosis frequency, and monthly admission trends

   Tools Used:

	•	Python (Pandas, NumPy)
	•	Jupyter Notebook 
	•	Excel/CSV for dataset

    Key Insights:

	•	Flu was the most common diagnosis
	•	Monthly admission patterns revealed trends over time
	•	Gender and age distribution highlighted patient demographics
